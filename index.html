Historical Reimaginator   [GitHub]

RAG-powered multi-agent app that reimagines history using a Wikipedia-backed vector knowledge base

Built an end-to-end Retrieval-Augmented Generation (RAG) application that explores alternate history scenarios by combining vector search with a multi-agent AI pipeline. Given any historical event, the app ingests Wikipedia articles into a Pinecone vector store using OpenAI embeddings, then orchestrates three specialized CrewAI agents — a Historian that retrieves grounded context via RAG before web search, an Alternate Reality agent for counterfactual analysis, and a Storyteller that crafts an immersive narrative — all served through an interactive Streamlit UI.

Pipeline

Wikipedia Ingest → Pinecone (RAG) → Historian Agent → Alt. Reality Agent → Storyteller Agent → Streamlit UI
